## 1. Introduction
Pixel-wise image segmentation assigns semantic labels to image pixels. This project evaluates a compact encoder-decoder baseline and one controlled architectural modification on the Oxford-IIIT Pet dataset.

## 2. Background Study
U-Net uses an encoder to extract hierarchical features, a decoder to restore spatial resolution, and skip connections to combine semantic and spatial information. Dilated convolution expands receptive field without additional pooling. This experiment changes only bottleneck dilation.

## 3. Methodology
### Dataset contract
Oxford-IIIT Pet RGB images and trimap masks; official trainval/test lists. Trainval is split into 85% train and 15% validation using seed 42; official test remains held out. Trimap 1=pet foreground, 2=background, 3=uncertain boundary and ignored in loss/metrics. Images resized to 256×256 bilinear; masks nearest-neighbor. RGB scaled to [0,1]. Horizontal flip is the only training augmentation. No pseudo-ground-truth labels.

### Proposed architecture
Input 3×256×256 → encoder blocks (32,64,128,256 channels; two 3×3 conv-BN-ReLU per block) with 2×2 max pooling → 512-channel bottleneck → four 2×2 transposed-convolution decoder stages with skip concatenation → 1×1 convolution → one foreground logit map.

Baseline bottleneck dilation=1. Controlled variant bottleneck dilation=2. All other model components and training settings are identical. Padding equals dilation to preserve feature-map dimensions.

### Training and comparison budget
Seed 42; batch 8; max 20 epochs; Adam lr=0.001; masked BCE-with-logits; early stopping patience 5 on validation Dice; best validation checkpoint. Record actual epochs and training time from run logs.

### Block diagram
```text
RGB 256x256
   ↓
Encoder 32 → Pool → Encoder 64 → Pool → Encoder 128 → Pool → Encoder 256 → Pool
   ↓
Bottleneck 512 (dilation 1 baseline / dilation 2 controlled variant)
   ↓
Upsample + skip-256 → Upsample + skip-128 → Upsample + skip-64 → Upsample + skip-32
   ↓
1x1 convolution → pet foreground probability
```
